# Tiny Theme Park

## Protótipo visual em Unity

**Status:** protótipo inicial em C# para **Unity 2022.3 LTS**, com cenário 3D criado automaticamente em Play Mode (sem modelos de terceiros). O núcleo de economia foi escrito sem dependências de Unity, permitindo testes automatizados.

### Abrir no Unity
1. Abra a pasta raiz no **Unity Hub** e escolha uma instalação compatível com Unity 2022.3 LTS.
2. Espere a importação dos scripts e abra ou crie uma cena 3D vazia.
3. Pressione **Play**. Um bootstrap com `RuntimeInitializeOnLoadMethod` gera o parque, câmera, árvores, caminhos, atrações e visitantes animados.

### Jogar
- O parque começa com 300 moedas e uma atração.
- O tempo de simulação avança um minuto a cada oito segundos.
- Visitantes e receitas aumentam de acordo com o número de atrações.
- Clique em **Construir atração** ou pressione **B** para expandir quando houver saldo.
-…

### Propósito declarado
Biblioteca/utilitário TypeScript de linha de comando para formatar e resumir métricas e **analisar tendências temporais por métrica**. O projeto ainda não inclui uma interface web, API ou coleta de telemetria real.

### Detalhes técnicos documentados
**Tecnologias**

- TypeScript e Node.js
- Executor de testes nativo do Node.js
- TypeScript Compiler para validação/build
- Sem dependências adicionais para análise de tendências

**Testes e CI**

A suíte cobre sumários, unidades com nomes especiais, valores não finitos, overflow, séries fora de ordem, métricas isoladas, baseline zero, timestamps e concorrência de identificadores. O workflow em `.github/workflows/ci.yml` executa `npm ci`, auditoria de dependências, build e testes em mudanças direcionadas à `main`.

**Evolução planejada**

- Adicionar uma interface web responsiva e gráficos.
- Integrar a coleta com uma API real, com autenticação e limites de uso.
- Adicionar agregação por janelas temporais e visualização de tendências.
