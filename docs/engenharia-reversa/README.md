- 100 READMEs e árvores Git recuperados; os privados permanecem nos próprios repositórios.

- 11 lotes de evidências estáticas, mais [complemento Dart/Elixir/Terraform](codigo-complemento.md).
- Foram identificados arquivos de código, build, testes, possíveis módulos de persistência e validação. Imports, declarações e rotas foram extraídos por padrões textuais; contagens não representam uma análise semântica completa.
- Rastreamento integral de chamadas, contratos, persistência, segurança e execução independente de testes: pendente. Não houve execução de testes nesta rodada.
